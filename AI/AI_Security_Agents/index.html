Deploy an AgentSkills AI Security Agent for Cloud-Hosted AI Models

A GitHub Pages-ready work procedure for designing, configuring, validating, and deploying an AI security agent that scans authorized cloud-hosted AI models, managed foundation model applications, RAG services, and agent tool chains.

Amazon BedrockAmazon SageMakerAzure AI FoundryAzure OpenAIAzure MLRAG + MCP Tools

Executive overview

The agent behaves as a controlled assessment orchestrator, not an unrestricted penetration-testing engine.

Purpose

Scan authorized cloud-hosted AI models and AI applications for configuration, telemetry, prompt-safety, RAG, tool-chain, and control weaknesses across AWS, Azure, and custom HTTPS deployments.

Governance model

Every scan is constrained by a signed scope file, explicit authorization, rate limits, stop conditions, and human escalation triggers before any cloud or endpoint action is taken.

Framework output

Findings are mapped to OWASP Top 10 for LLM Applications, MITRE ATLAS, NIST AI RMF, and NIST CSF so results are usable by security leadership, engineers, and audit stakeholders.

What the agent can scan

The scanner evaluates managed AI services, customer-owned ML deployments, cloud posture, RAG, tool usage, and telemetry.

Hosting patternAssessment coverage
Amazon BedrockSeparate Bedrock scan track covering managed foundation model access, guardrail configuration, application prompt behavior, Bedrock agent/RAG integration, CloudTrail/CloudWatch evidence, and bounded Bedrock Runtime tests under the Bedrock scanner role.
Amazon SageMakerSeparate SageMaker scan track covering online endpoints, endpoint configurations, model metadata, customer model containers, data capture, Model Monitor posture, VPC/network exposure, SageMaker logs/metrics, and bounded InvokeEndpoint tests under the SageMaker scanner role.
Azure AI Foundry / Azure OpenAIModel deployments, safety evaluations, content-safety posture, app/agent behavior, endpoint access, observability, tracing, and evaluation results.
Azure Machine Learning online endpointsEndpoint auth, network exposure, deployment details, monitor/log integration, model behavior tests, container and scoring script review where accessible.
EKS/AKS/ECS/Container Apps/App Service/custom APIsContainer image posture, API gateway exposure, secrets, IAM/managed identity, RAG data sources, prompt templates, tool manifests, and runtime behavior.

Important limitation

For managed foundation models such as provider-hosted Bedrock base models or Azure OpenAI models, the scanner does not inspect provider-owned model weights. It assesses configuration, access paths, guardrails, telemetry, and behavior through approved invocations. For customer-owned models, artifact review depends on explicit read access.

Prerequisites

Complete these items before configuring the skill or running a scan.

Governance prerequisites

  • Approved scope file listing cloud accounts/subscriptions, regions, endpoints, model deployments, RAG stores, and allowed test categories.
  • Change ticket or security assessment authorization with expiration date.
  • Named business owner, technical owner, and security reviewer for production targets.
  • Rate limits, stop conditions, escalation triggers, and evidence-handling rules.

Technical prerequisites

  • Python 3.11+ and Node.js 18+.
  • AgentSkills-compatible agent client or MCP-compatible orchestrator.
  • AWS CLI plus scanner role with STS AssumeRole access into approved accounts.
  • Azure CLI plus service principal, workload identity, or managed identity.
  • Outbound network path to cloud control planes and approved inference endpoints.

Implementation procedure

The procedure follows the AgentSkills progressive-disclosure model: discover metadata, load the workflow, execute bounded logic, collect evidence, and render reports.

Phase 1 — Design and skill discovery

  • Create or import the cloud-hosted AI model security scan skill into the registry.
  • Use discoverable frontmatter fields and supported subdomains.
  • Define mappings to OWASP LLM Top 10, MITRE ATLAS, NIST AI RMF, and NIST CSF.
  • Define non-destructive testing policy and approval requirements.

Phase 2 — Skill configuration and validation

  • Keep SKILL.md frontmatter flat.
  • Require name, description, domain, subdomain, and tags.
  • Keep framework mapping fields at the top level.
  • Validate both SKILL.md metadata and scan_scope.yaml before execution.

Phase 3 — Cloud identity and permissions

  • Use a dedicated AWS scanner role and Azure custom role.
  • Grant read-only inventory and logging permissions by default.
  • Restrict invocation permissions to approved resources only.
  • Use short-lived credentials; never store secrets in SKILL.md or source control.

Phase 4 — Execution logic

  • Run deterministic scripts for scope validation, inventory, posture checks, endpoint probes, evidence collection, and report generation.
  • Perform only approved prompt, leakage, RAG, tool, and control checks.
  • Write findings as structured JSON with evidence, mappings, severity, confidence, and remediation.

Phase 5 — Deployment sequence

  • Create a controlled skills directory or private repository.
  • Install dependencies and the public cybersecurity skills library.
  • Authenticate to AWS and Azure using approved identities.
  • Validate skill metadata and scope before any scan.
  • Run the scanner, store protected evidence, render reports, and review findings before distribution or ticket creation.

# Cloud Hosted AI Model Security Scan
 
## When to Use
Use this skill when a user asks to assess an authorized AI model, AI application,
RAG service, agent, or inference endpoint deployed in AWS, Azure, Kubernetes, or a
custom HTTPS API. The skill is appropriate for Amazon Bedrock, Amazon SageMaker,
Azure AI Foundry, Azure OpenAI, Azure Machine Learning online endpoints, AKS/EKS,
container-hosted inference APIs, and API-gateway fronted model services.
 
## Safety Rules
1. Only assess targets listed in the signed scope file.
2. Do not attempt credential extraction, destructive exploitation, data exfiltration,
   brute-force testing, denial-of-service, or rate-limit bypass.
3. Use read-only cloud permissions except for explicitly approved inference calls.
4. Use the configured rate limits and stop conditions.
5. Escalate to a human reviewer if a test could expose regulated data, invoke a tool
   with side effects, or materially alter a production workload.
 
## Prerequisites
- Python 3.11 or later.
- Node.js 18 or later for the `skills` installer.
- AWS role access for approved accounts and regions.
- Azure service principal or workload identity for approved subscriptions.
- Written approval for every endpoint, model, RAG index, and agent tool to be tested.
- A configured `scan_scope.yaml` file.
 
## Workflow
1. Validate the scope file.
2. Identify target cloud provider and model hosting pattern.
3. Collect endpoint, model, IAM, network, guardrail, logging, and telemetry metadata.
4. Run only approved adversarial prompt, leakage, tool-abuse, and RAG tests.
5. Analyze artifacts, containers, SBOMs, prompts, retrievers, and tool manifests where access exists.
6. Map findings to OWASP LLM Top 10, MITRE ATLAS, NIST AI RMF, and NIST CSF.
7. Generate JSON, Markdown, and executive-summary outputs.
 
## Commands
```bash
python scripts/validate_scope.py --scope scan_scope.yaml
python scripts/agent.py --scope scan_scope.yaml --out out/findings.json
python scripts/render_report.py --findings out/findings.json --out out/report.md
```
 
## Human Escalation Criteria
Escalate immediately when the scanner observes possible regulated data exposure,
production guardrail bypass, tool invocation with external side effects, missing logging
on a high-risk endpoint, overly permissive cloud IAM, public network exposure of a
sensitive inference endpoint, or evidence of active compromise.
 
## Expected Outputs
- `out/findings.json`: structured evidence and framework mappings.
- `out/evidence/*.jsonl`: raw collection records with timestamps and hashes.

scripts/validate_scope.py
#!/usr/bin/env python3
"""Validate the cloud AI model scan scope before any cloud or endpoint action."""
from __future__ import annotations

import argparse
import datetime as dt
import ipaddress
import socket
import sys
from pathlib import Path
from typing import Any
from urllib.parse import urlparse

import yaml

REQUIRED_TOP_LEVEL = {"scan_id", "owner", "authorization", "safety", "frameworks", "output"}
FORBIDDEN_FLAGS = {"allow_destructive_tests", "allow_data_exfiltration_tests"}
METADATA_IPS = {"169.254.169.254", "169.254.170.2", "100.100.100.200"}
AUTH_MODES = {"azure-ad", "env-bearer", "env-api-key"}


def _die(message: str) -> None:
    print(f"[scope-invalid] {message}", file=sys.stderr)
    raise SystemExit(2)


def load_scope(path: Path) -> dict[str, Any]:
    try:
        data = yaml.safe_load(path.read_text(encoding="utf-8"))
    except FileNotFoundError as exc:
        raise SystemExit(f"scope file not found: {path}") from exc
    except yaml.YAMLError as exc:
        raise SystemExit(f"invalid YAML scope file: {path}: {exc}") from exc
    if not isinstance(data, dict):
        _die("scope file must contain a YAML mapping")
    return data


def validate_expiry(scope: dict[str, Any]) -> None:
    auth = scope.get("authorization") or {}
    for key in ("approval_ticket", "approved_by", "expires_utc"):
        if not auth.get(key):
            _die(f"authorization.{key} is required")
    try:
        expiry = dt.datetime.fromisoformat(str(auth["expires_utc"]).replace("Z", "+00:00"))
    except ValueError:
        _die("authorization.expires_utc must be ISO-8601")
    if expiry.tzinfo is None:
        expiry = expiry.replace(tzinfo=dt.timezone.utc)
    if expiry.astimezone(dt.timezone.utc) <= dt.datetime.now(dt.timezone.utc):
        _die("authorization has expired")


def validate_output(scope: dict[str, Any]) -> None:
    output_root = (scope.get("output") or {}).get("output_root")
    if not output_root:
        _die("output.output_root is required")
    Path(str(output_root)).expanduser().resolve()


def validate_safety(scope: dict[str, Any]) -> None:
    safety = scope.get("safety") or {}
    max_requests = safety.get("max_requests_per_endpoint")
    timeout = safety.get("request_timeout_seconds")
    if not isinstance(max_requests, int) or not (1 <= max_requests <= 100):
        _die("safety.max_requests_per_endpoint must be an integer between 1 and 100")
    if not isinstance(timeout, int) or not (1 <= timeout <= 60):
        _die("safety.request_timeout_seconds must be an integer between 1 and 60")
    for flag in FORBIDDEN_FLAGS:
        if safety.get(flag) is True:
            _die(f"{flag} must be false for this scanner")
    if safety.get("allow_private_endpoint"):
        cidrs = safety.get("approved_private_cidrs") or []
        try:
            [ipaddress.ip_network(cidr) for cidr in cidrs]
        except ValueError as exc:
            _die(f"invalid approved_private_cidrs entry: {exc}")


def approved_hosts(scope: dict[str, Any]) -> set[str]:
    """Return only the explicit host allowlist. Endpoint definitions are not self-approving."""
    return set(scope.get("safety", {}).get("approved_endpoint_hosts", []) or [])


def private_networks(scope: dict[str, Any]) -> list[ipaddress._BaseNetwork]:
    cidrs = scope.get("safety", {}).get("approved_private_cidrs") or []
    return [ipaddress.ip_network(cidr) for cidr in cidrs]


def _ip_allowed(ip: ipaddress._BaseAddress, allow_private: bool, private_cidrs: list[ipaddress._BaseNetwork]) -> bool:
    if str(ip) in METADATA_IPS or ip.is_loopback or ip.is_link_local:
        return False
    if ip.is_private:
        return allow_private and any(ip in net for net in private_cidrs)
    return True


def _host_resolves_to_allowed_ips(hostname: str, allow_private: bool, private_cidrs: list[ipaddress._BaseNetwork]) -> bool:
    try:
        literal = ipaddress.ip_address(hostname)
        return _ip_allowed(literal, allow_private, private_cidrs)
    except ValueError:
        pass
    try:
        results = socket.getaddrinfo(hostname, None)
    except socket.gaierror:
        return True
    for result in results:
        ip = ipaddress.ip_address(result[4][0])
        if not _ip_allowed(ip, allow_private, private_cidrs):
            return False
    return True


def validate_endpoint_url(url: str, allowlist: set[str], allow_private: bool = False, private_cidrs: list[ipaddress._BaseNetwork] | None = None) -> None:
    parsed = urlparse(url)
    if parsed.scheme != "https" or not parsed.hostname:
        _die(f"endpoint must be HTTPS with hostname: {url}")
    if parsed.hostname not in allowlist:
        _die(f"endpoint host is outside approved scope: {parsed.hostname}")
    if not _host_resolves_to_allowed_ips(parsed.hostname, allow_private, private_cidrs or []):
        _die(f"endpoint host resolves to a prohibited or unapproved private address: {parsed.hostname}")


def _require_endpoint_auth(ep: dict[str, Any], context: str) -> None:
    mode = ep.get("auth_mode")
    if mode not in AUTH_MODES:
        _die(f"{context} invoke_allowed endpoint requires auth_mode in {sorted(AUTH_MODES)}")
    if mode in {"env-bearer", "env-api-key"} and not ep.get("auth_header_env"):
        _die(f"{context} endpoint with {mode} requires auth_header_env")
    if mode == "azure-ad" and not ep.get("aad_scope"):
        _die(f"{context} endpoint with azure-ad requires aad_scope")


def validate_cloud_targets(scope: dict[str, Any]) -> None:
    if not scope.get("aws", {}).get("enabled") and not scope.get("azure", {}).get("enabled") and not scope.get("custom_endpoints"):
        _die("at least one AWS, Azure, or custom endpoint target must be enabled")
    hosts = approved_hosts(scope)
    allow_private = bool(scope.get("safety", {}).get("allow_private_endpoint"))
    private_cidrs = private_networks(scope)

    for account in scope.get("aws", {}).get("accounts", []) or []:
        if not account.get("regions"):
            _die("each AWS account requires regions")
        services = set(account.get("include_services", []) or [])
        roles = account.get("scanner_roles") or {}
        bedrock_role = roles.get("bedrock_role_arn")
        sagemaker_role = roles.get("sagemaker_role_arn")
        if "bedrock" in services and not bedrock_role:
            _die("AWS Bedrock scans require scanner_roles.bedrock_role_arn")
        if "sagemaker" in services and not sagemaker_role:
            _die("AWS SageMaker scans require scanner_roles.sagemaker_role_arn")
        if {"bedrock", "sagemaker"}.issubset(services) and bedrock_role == sagemaker_role:
            _die("Bedrock and SageMaker scanner roles must be separate for least-privilege scanning")
        for ep in account.get("endpoints", []) or []:
            if ep.get("invoke_allowed") and ep.get("type") == "bedrock-runtime" and not ep.get("model_arn"):
                _die("approved Bedrock runtime endpoint requires model_arn for IAM least-privilege review")
            if ep.get("invoke_allowed") and ep.get("type") == "sagemaker" and not ep.get("endpoint_arn"):
                _die("approved SageMaker endpoint requires endpoint_arn for IAM least-privilege review")

    for sub in scope.get("azure", {}).get("subscriptions", []) or []:
        if not sub.get("subscription_id"):
            _die("each Azure subscription requires subscription_id")
        for ep in sub.get("endpoints", []) or []:
            endpoint = ep.get("endpoint") or ep.get("scoring_uri")
            if ep.get("invoke_allowed"):
                _require_endpoint_auth(ep, f"Azure {ep.get('type', 'endpoint')}")
                if endpoint:
                    validate_endpoint_url(endpoint, hosts, allow_private, private_cidrs)

    for ep in scope.get("custom_endpoints", []) or []:
        if ep.get("invoke_allowed"):
            _require_endpoint_auth(ep, f"custom endpoint {ep.get('name', 'unnamed')}")
            validate_endpoint_url(ep.get("url", ""), hosts, allow_private, private_cidrs)


def validate(scope: dict[str, Any]) -> None:
    missing = REQUIRED_TOP_LEVEL - set(scope)
    if missing:
        _die(f"missing required top-level fields: {sorted(missing)}")
    validate_expiry(scope)
    validate_output(scope)
    validate_safety(scope)
    validate_cloud_targets(scope)

def now_iso() -> str:
    return dt.datetime.now(dt.timezone.utc).isoformat()


def stable_id(*parts: str) -> str:
    return hashlib.sha256("|".join(parts).encode()).hexdigest()[:16]


SENSITIVE_KEY_NAMES = {
    "authorization", "api_key", "apikey", "access_key", "secret", "secret_key",
    "token", "password", "credential", "credentials", "client_secret",
    "aws_secret_access_key", "aws_session_token", "subscription_key",
}

SECRET_PATTERNS = [
    re.compile(r"(?i)(bearer\s+)[a-z0-9._\-+/=]{12,}"),
    re.compile(r"(?i)(api[_-]?key\s*[:=]\s*)[a-z0-9._\-+/=]{8,}"),
    re.compile(r"(?i)(password\s*[:=]\s*)\S+"),
    re.compile(r"(?i)(secret\s*[:=]\s*)\S+"),
    re.compile(r"AKIA[0-9A-Z]{16}"),
]


def redact_text(value: str) -> str:
    redacted = value
    for pattern in SECRET_PATTERNS:
        redacted = pattern.sub(lambda match: (match.group(1) if match.lastindex else "") + "[REDACTED]", redacted)
    return redacted


def redact_record(value: Any) -> Any:
    if isinstance(value, dict):
        clean: dict[str, Any] = {}
        for key, item in value.items():
            key_l = key.lower()
            if key_l in SENSITIVE_KEY_NAMES or any(marker in key_l for marker in ("secret", "token", "password", "credential", "authorization")):
                clean[key] = "[REDACTED]"
            else:
                clean[key] = redact_record(item)
        return clean
    if isinstance(value, list):
        return [redact_record(item) for item in value]
    if isinstance(value, str):
        return redact_text(value)
    return value


def safe_excerpt(value: str, limit: int = 1000) -> str:
    return redact_text(str(value).replace("\n", " "))[:limit]


def safe_url_id(url: str) -> str:
    parsed = urlparse(url)
    path = parsed.path or "/"
    return f"{parsed.scheme}://{parsed.hostname}{path}"

def load_prompt_probes(scope: dict[str, Any]) -> list[dict[str, Any]]:
    configured = scope.get("assets", {}).get("prompt_probes_file")
    if not configured:
        return DEFAULT_SAFE_PROMPTS
    path = Path(configured)
    if not path.exists():
        return DEFAULT_SAFE_PROMPTS
    probes = json.loads(path.read_text(encoding="utf-8"))
    if not isinstance(probes, list):
        raise ValueError("assets.prompt_probes_file must contain a JSON list")
    for probe in probes:
        if not {"id", "category", "prompt", "fail_indicators"}.issubset(probe):
            raise ValueError("each prompt probe requires id, category, prompt, and fail_indicators")
    return probes


class EvidenceWriter:
    def __init__(self, out_path: Path):
        self.path = out_path.with_suffix(".evidence.jsonl")
        self.path.parent.mkdir(parents=True, exist_ok=True)

    def write(self, source: str, record: dict[str, Any]) -> None:
        redacted_record = redact_record(record)
        body = json.dumps(redacted_record, sort_keys=True, default=str)
        wrapped = {
            "timestamp": now_iso(),
            "source": source,
            "sha256": hashlib.sha256(body.encode()).hexdigest(),
            "record": redacted_record,
            "redacted": True,
        }
        with self.path.open("a", encoding="utf-8") as handle:
            handle.write(json.dumps(wrapped, default=str) + "\n")


def record_finding(findings: list[Finding], **kwargs: Any) -> None:
    findings.append(Finding(**kwargs))


def auth_headers_for_endpoint(ep: dict[str, Any], credential: DefaultAzureCredential | None = None) -> dict[str, str]:
    mode = ep.get("auth_mode")
    if mode == "azure-ad":
        if credential is None:
            raise ValueError("azure-ad endpoint auth requires an Azure credential")
        token = credential.get_token(ep["aad_scope"]).token
        return {"Authorization": f"Bearer {token}"}
    if mode == "env-bearer":
        token = os.environ.get(ep["auth_header_env"])
        if not token:
            raise ValueError(f"missing required environment variable {ep['auth_header_env']}")
        return {"Authorization": f"Bearer {token}"}
    if mode == "env-api-key":
        key = os.environ.get(ep["auth_header_env"])
        if not key:
            raise ValueError(f"missing required environment variable {ep['auth_header_env']}")
        return {ep.get("auth_header_name", "api-key"): key}
    raise ValueError(f"unsupported or missing auth_mode: {mode}")


class AwsScanner:
    def __init__(self, account: dict[str, Any], safety: dict[str, Any], evidence: EvidenceWriter, probes: list[dict[str, Any]]):
        self.account = account
        self.safety = safety
        self.evidence = evidence
        self.probes = probes
        self.config = Config(retries={"max_attempts": 3, "mode": "standard"})

    def _role_arn_for(self, service: str) -> str:
        roles = self.account.get("scanner_roles") or {}
        if service == "bedrock":
            return roles["bedrock_role_arn"]
        if service == "sagemaker":
            return roles["sagemaker_role_arn"]
        raise ValueError(f"unsupported AWS scanner service: {service}")

    def _session_for(self, service: str) -> boto3.Session:
        role_arn = self._role_arn_for(service)
        sts = boto3.client("sts", config=self.config)
        assumed = sts.assume_role(RoleArn=role_arn, RoleSessionName=f"cloud-ai-model-security-scan-{service}")
        creds = assumed["Credentials"]
        return boto3.Session(
            aws_access_key_id=creds["AccessKeyId"],
            aws_secret_access_key=creds["SecretAccessKey"],
            aws_session_token=creds["SessionToken"],
        )

    def scan(self) -> list[Finding]:
        findings: list[Finding] = []
        sessions: dict[str, boto3.Session] = {}
        services = set(self.account.get("include_services", []) or [])
        for service in ("bedrock", "sagemaker"):
            if service not in services:
                continue
            try:
                sessions[service] = self._session_for(service)
            except (ClientError, BotoCoreError, KeyError, ValueError) as exc:
                role_arn = (self.account.get("scanner_roles") or {}).get(f"{service}_role_arn", "missing")
                record_finding(findings, finding_id=stable_id("aws", self.account.get("account_id", "unknown"), service, "assume-role"), title=f"AWS {service} scanner role assumption failed", severity="High", confidence="High", provider="aws", resource_type="iam-role", resource_id=role_arn, description=f"Scanner could not assume the approved {service} least-privilege role.", evidence={"error": safe_excerpt(str(exc)), "timestamp": now_iso()}, owasp=[], atlas=[], nist_ai_rmf=["GOVERN-1.1"], nist_csf=["PR.AA-05"], remediation="Verify trust policy, IAM Identity Center permission set, and scanner role permissions.")

        for region in self.account.get("regions", []):
            if "bedrock" in sessions:
                findings.extend(self._scan_bedrock(sessions["bedrock"], region))
            if "sagemaker" in sessions:
                findings.extend(self._scan_sagemaker(sessions["sagemaker"], region))
        findings.extend(self._scan_approved_runtime_endpoints(sessions))
        return findings

    def _scan_bedrock(self, session: boto3.Session, region: str) -> list[Finding]:
        findings: list[Finding] = []
        try:
            client = session.client("bedrock", region_name=region, config=self.config)
            models = client.list_foundation_models().get("modelSummaries", [])
            self.evidence.write("aws-bedrock-inventory", {"region": region, "model_count": len(models)})
            record_finding(findings, finding_id=stable_id("aws", region, "bedrock-inventory"), title="Amazon Bedrock foundation model inventory collected", severity="Informational", confidence="High", provider="aws", resource_type="bedrock", resource_id=region, description="Approved inventory collection identified available Bedrock models for AI security review.", evidence={"region": region, "model_count": len(models), "timestamp": now_iso()}, owasp=[], atlas=[], nist_ai_rmf=["MAP-1.1"], nist_csf=["ID.AM-02"], remediation="Confirm allowed models, guardrails, logging, and approved application ownership.")
        except (ClientError, BotoCoreError) as exc:
            self.evidence.write("aws-bedrock-error", {"region": region, "error": safe_excerpt(str(exc))})
        return findings

    def _scan_sagemaker(self, session: boto3.Session, region: str) -> list[Finding]:
        findings: list[Finding] = []
        try:
            client = session.client("sagemaker", region_name=region, config=self.config)
            endpoints = client.list_endpoints().get("Endpoints", [])
            self.evidence.write("aws-sagemaker-inventory", {"region": region, "endpoint_count": len(endpoints)})
            for ep in endpoints:
                record_finding(findings, finding_id=stable_id("aws", region, ep["EndpointName"], "sagemaker"), title="SageMaker endpoint inventory evidence collected", severity="Informational", confidence="High", provider="aws", resource_type="sagemaker-endpoint", resource_id=ep["EndpointName"], description="Approved inventory collection identified a SageMaker endpoint for posture and logging review.", evidence={"region": region, "status": ep.get("EndpointStatus"), "timestamp": now_iso()}, owasp=[], atlas=[], nist_ai_rmf=["MAP-1.1"], nist_csf=["ID.AM-02"], remediation="Confirm endpoint authentication, network isolation, data capture, Model Monitor, and KMS configuration.")
        except (ClientError, BotoCoreError) as exc:
            self.evidence.write("aws-sagemaker-error", {"region": region, "error": safe_excerpt(str(exc))})
        return findings

    def _scan_approved_runtime_endpoints(self, sessions: dict[str, boto3.Session]) -> list[Finding]:
        findings: list[Finding] = []
        for ep in self.account.get("endpoints", []) or []:
            if not ep.get("invoke_allowed"):
                continue
            if ep.get("type") == "bedrock-runtime" and "bedrock" in sessions:
                findings.extend(self._invoke_bedrock_probe(sessions["bedrock"], ep))
            if ep.get("type") == "sagemaker" and "sagemaker" in sessions:
                findings.extend(self._invoke_sagemaker_probe(sessions["sagemaker"], ep))
        return findings

    def _invoke_bedrock_probe(self, session: boto3.Session, ep: dict[str, Any]) -> list[Finding]:
        findings: list[Finding] = []
        client = session.client("bedrock-runtime", region_name=ep["region"], config=self.config)
        for probe in self.probes[: int(self.safety.get("max_requests_per_endpoint", 25))]:
            try:
                body = json.dumps({"anthropic_version": "bedrock-2023-05-31", "max_tokens": 128, "messages": [{"role": "user", "content": probe["prompt"]}]})
                response = client.invoke_model(modelId=ep["model_id"], contentType="application/json", accept="application/json", body=body)
                text = response["body"].read().decode("utf-8", errors="ignore")
                self._evaluate_probe(findings, "aws", "bedrock-runtime", ep["model_id"], probe, text)
            except Exception as exc:
                self.evidence.write("aws-bedrock-runtime-error", {"model_id": ep.get("model_id"), "error": safe_excerpt(str(exc))})
        return findings

    def _invoke_sagemaker_probe(self, session: boto3.Session, ep: dict[str, Any]) -> list[Finding]:
        findings: list[Finding] = []
        client = session.client("sagemaker-runtime", region_name=ep["region"], config=self.config)
        for probe in self.probes[: int(self.safety.get("max_requests_per_endpoint", 25))]:
            try:
                response = client.invoke_endpoint(EndpointName=ep["endpoint_name"], ContentType="application/json", Body=json.dumps({"input": probe["prompt"]}))
                text = response["Body"].read().decode("utf-8", errors="ignore")
                self._evaluate_probe(findings, "aws", "sagemaker-endpoint", ep["endpoint_name"], probe, text)
            except Exception as exc:
                self.evidence.write("aws-sagemaker-runtime-error", {"endpoint_name": ep.get("endpoint_name"), "error": safe_excerpt(str(exc))})
        return findings

    def _evaluate_probe(self, findings: list[Finding], provider: str, resource_type: str, resource_id: str, probe: dict[str, Any], text: str) -> None:
        indicators = [i for i in probe["fail_indicators"] if i.lower() in text.lower()]
        if indicators:
            category = probe["category"]
            record_finding(findings, finding_id=stable_id(provider, resource_id, probe["id"], "failed"), title=f"Endpoint response matched {category} failure indicator", severity="High" if category in {"prompt_injection", "tool_abuse"} else "Medium", confidence="Medium", provider=provider, resource_type=resource_type, resource_id=resource_id, description="An approved safety probe produced output matching configured failure indicators.", evidence={"probe_id": probe["id"], "matched_indicators": indicators, "response_excerpt": safe_excerpt(text), "timestamp": now_iso()}, owasp=[OWASP_MAP.get(category, "LLM01")], atlas=[ATLAS_MAP.get(category, "AML.T0051")], nist_ai_rmf=["MEASURE-2.6", "MANAGE-2.4"], nist_csf=["DE.CM-01", "RS.AN-03"], remediation="Tune prompt-injection defenses, output filtering, tool-call policy, retrieval grounding, and human approval gates.")


class AzureScanner:
    def __init__(self, tenant_id: str | None, subscription: dict[str, Any], safety: dict[str, Any], hosts: set[str], evidence: EvidenceWriter, probes: list[dict[str, Any]], allow_private: bool, private_cidrs: list[Any]):
        self.tenant_id = tenant_id
        self.subscription = subscription
        self.safety = safety
        self.hosts = hosts
        self.evidence = evidence
        self.probes = probes
        self.allow_private = allow_private
        self.private_cidrs = private_cidrs
        self.credential = DefaultAzureCredential()

    def scan(self) -> list[Finding]:
        findings: list[Finding] = []
        subscription_id = self.subscription["subscription_id"]
        try:
            resource_client = ResourceManagementClient(self.credential, subscription_id)
            resources = list(resource_client.resources.list())
            self.evidence.write("azure-resource-inventory", {"subscription_id": subscription_id, "resource_count": len(resources)})
            record_finding(findings, finding_id=stable_id("azure", subscription_id, "inventory"), title="Azure AI resource inventory collected", severity="Informational", confidence="High", provider="azure", resource_type="subscription", resource_id=subscription_id, description="Approved inventory collection identified Azure resources for AI security review.", evidence={"resource_count": len(resources), "timestamp": now_iso()}, owasp=[], atlas=[], nist_ai_rmf=["MAP-1.1"], nist_csf=["ID.AM-02"], remediation="Confirm AI services, endpoint exposure, diagnostic settings, private endpoint usage, and content-safety configuration.")

        findings.extend(self._probe_approved_endpoints())
        return findings

    def _probe_approved_endpoints(self) -> list[Finding]:
        findings: list[Finding] = []
        for ep in self.subscription.get("endpoints", []) or []:
            if not ep.get("invoke_allowed"):
                continue
            url = ep.get("endpoint") or ep.get("scoring_uri")
            if not url:
                continue
            findings.extend(EndpointHarness("azure", ep.get("type", "endpoint"), url, ep, self.safety, self.hosts, self.evidence, self.probes, self.credential, self.allow_private, self.private_cidrs).run())
        return findings


class EndpointHarness:
    def __init__(self, provider: str, resource_type: str, url: str, endpoint_cfg: dict[str, Any], safety: dict[str, Any], hosts: set[str], evidence: EvidenceWriter, probes: list[dict[str, Any]], credential: DefaultAzureCredential | None = None, allow_private: bool = False, private_cidrs: list[Any] | None = None):
        self.provider = provider
        self.resource_type = resource_type
        self.url = url
        self.endpoint_cfg = endpoint_cfg
        self.safety = safety
        self.hosts = hosts
        self.evidence = evidence
        self.probes = probes
        self.credential = credential
        self.allow_private = allow_private
        self.private_cidrs = private_cidrs or []

    def run(self) -> list[Finding]:
        validate_endpoint_url(self.url, self.hosts, self.allow_private, self.private_cidrs)
        headers = {"Content-Type": "application/json", **auth_headers_for_endpoint(self.endpoint_cfg, self.credential)}
        findings: list[Finding] = []
        timeout = int(self.safety.get("request_timeout_seconds", 30))
        max_requests = int(self.safety.get("max_requests_per_endpoint", 25))
        for probe in self.probes[:max_requests]:
            try:
                response = requests.post(self.url, json={"input": probe["prompt"]}, headers=headers, timeout=timeout)
                text = response.text
                self.evidence.write("endpoint-probe", {"url": safe_url_id(self.url), "probe_id": probe["id"], "status_code": response.status_code})
                indicators = [i for i in probe["fail_indicators"] if i.lower() in text.lower()]
                if indicators:
                    category = probe["category"]
                    record_finding(findings, finding_id=stable_id(self.provider, self.url, probe["id"], "indicator"), title=f"Endpoint response matched {category} indicator", severity="High" if category in {"prompt_injection", "tool_abuse"} else "Medium", confidence="Medium", provider=self.provider, resource_type=self.resource_type, resource_id=safe_url_id(self.url), description="An approved safety probe produced output matching configured failure indicators.", evidence={"probe_id": probe["id"], "status_code": response.status_code, "matched_indicators": indicators, "response_excerpt": safe_excerpt(text), "timestamp": now_iso()}, owasp=[OWASP_MAP.get(category, "LLM01")], atlas=[ATLAS_MAP.get(category, "AML.T0051")], nist_ai_rmf=["MEASURE-2.6", "MANAGE-2.4"], nist_csf=["DE.CM-01", "RS.AN-03"], remediation="Tune safety policy, endpoint authentication, prompt isolation, and output filtering.")
            except Exception as exc:
                record_finding(findings, finding_id=stable_id(self.provider, self.url, probe["id"], "probe-error"), title="Approved endpoint probe failed", severity="Low", confidence="High", provider=self.provider, resource_type=self.resource_type, resource_id=safe_url_id(self.url), description="The scanner could not complete an approved non-destructive prompt probe.", evidence={"probe_id": probe["id"], "error": safe_excerpt(str(exc)), "timestamp": now_iso()}, owasp=[], atlas=[], nist_ai_rmf=["MEASURE-2.6"], nist_csf=["RS.AN-03"], remediation="Verify endpoint availability, authentication mode, and approved route before rerunning.")
            time.sleep(0.2)
        return findings


def run_scan(scope: dict[str, Any], out: Path) -> list[Finding]:
    validate(scope)
    output_path = validate_output_path(scope, out)
    evidence = EvidenceWriter(output_path)
    probes = load_prompt_probes(scope)
    findings: list[Finding] = []
    safety = scope.get("safety", {})
    if scope.get("aws", {}).get("enabled"):
        for account in scope.get("aws", {}).get("accounts", []) or []:
            findings.extend(AwsScanner(account, safety, evidence, probes).scan())
    if scope.get("azure", {}).get("enabled"):
        hosts = approved_hosts(scope)
        allow_private = bool(safety.get("allow_private_endpoint"))
        cidrs = private_networks(scope)
        for sub in scope.get("azure", {}).get("subscriptions", []) or []:
            findings.extend(AzureScanner(scope.get("azure", {}).get("tenant_id"), sub, safety, hosts, evidence, probes, allow_private, cidrs).scan())
    for ep in scope.get("custom_endpoints", []) or []:
        if ep.get("invoke_allowed"):
            findings.extend(EndpointHarness("custom", ep.get("name", "custom-endpoint"), ep["url"], ep, safety, approved_hosts(scope), evidence, probes, None, bool(safety.get("allow_private_endpoint")), private_networks(scope)).run())
    write_json(output_path, [asdict(f) for f in findings])
    return findings


def main() -> int:
    parser = argparse.ArgumentParser(description="Run cloud-hosted AI model security scan")
    parser.add_argument("--scope", required=True, type=Path)
    parser.add_argument("--out", required=True, type=Path)
    args = parser.parse_args()
    scope = load_yaml(args.scope)
    findings = run_scan(scope, args.out)
    print(json.dumps({"findings": len(findings), "out": str(validate_output_path(scope, args.out))}, indent=2))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

#!/usr/bin/env python3
"""Render scanner findings into a redacted Markdown report with optional template support."""
from __future__ import annotations

import argparse
import json
import re
from collections import Counter, defaultdict
from pathlib import Path
from typing import Any

SENSITIVE_KEY_NAMES = {
    "authorization", "api_key", "apikey", "access_key", "secret", "secret_key",
    "token", "password", "credential", "credentials", "client_secret",
    "aws_secret_access_key", "aws_session_token", "subscription_key",
}

SECRET_PATTERNS = [
    re.compile(r"(?i)(bearer\s+)[a-z0-9._\-+/=]{12,}"),
    re.compile(r"(?i)(api[_-]?key\s*[:=]\s*)[a-z0-9._\-+/=]{8,}"),
    re.compile(r"(?i)(password\s*[:=]\s*)\S+"),
    re.compile(r"(?i)(secret\s*[:=]\s*)\S+"),
    re.compile(r"AKIA[0-9A-Z]{16}"),
]


def redact_text(value: str) -> str:
    redacted = value
    for pattern in SECRET_PATTERNS:
        redacted = pattern.sub(lambda match: (match.group(1) if match.lastindex else "") + "[REDACTED]", redacted)
    return redacted


def redact_record(value: Any) -> Any:
    if isinstance(value, dict):
        clean: dict[str, Any] = {}
        for key, item in value.items():
            key_l = key.lower()
            if key_l in SENSITIVE_KEY_NAMES or any(marker in key_l for marker in ("secret", "token", "password", "credential", "authorization")):
                clean[key] = "[REDACTED]"
            else:
                clean[key] = redact_record(item)
        return clean
    if isinstance(value, list):
        return [redact_record(item) for item in value]
    if isinstance(value, str):
        return redact_text(value)
    return value


def safe_text(value: Any) -> str:
    return redact_text(str(value if value is not None else "N/A"))


def severity_rank(value: str) -> int:
    return {"Critical": 0, "High": 1, "Medium": 2, "Low": 3, "Informational": 4}.get(value, 5)


def load_findings(path: Path) -> list[dict[str, Any]]:
    data = json.loads(path.read_text(encoding="utf-8"))
    if not isinstance(data, list):
        raise ValueError("findings file must contain a list")
    return [redact_record(item) for item in data]


def severity_table(findings: list[dict[str, Any]]) -> str:
    counts = Counter(f.get("severity", "Unknown") for f in findings)
    lines = ["| Severity | Count |", "|---|---:|"]
    for sev in ["Critical", "High", "Medium", "Low", "Informational", "Unknown"]:
        if counts.get(sev):
            lines.append(f"| {sev} | {counts[sev]} |")
    return "\n".join(lines)


def provider_table(findings: list[dict[str, Any]]) -> str:
    by_provider = defaultdict(int)
    for f in findings:
        by_provider[f.get("provider", "unknown")] += 1
    lines = ["| Provider | Count |", "|---|---:|"]
    for provider, count in sorted(by_provider.items()):
        lines.append(f"| {safe_text(provider)} | {count} |")
    return "\n".join(lines)


def detailed_findings(findings: list[dict[str, Any]]) -> str:
    lines: list[str] = []
    for f in sorted(findings, key=lambda x: severity_rank(x.get("severity", "Unknown"))):
        lines.append(f"### {safe_text(f.get('title', 'Untitled finding'))}")
        lines.append(f"- **Finding ID:** `{safe_text(f.get('finding_id'))}`")
        lines.append(f"- **Severity:** {safe_text(f.get('severity'))} / **Confidence:** {safe_text(f.get('confidence'))}")
        lines.append(f"- **Provider:** {safe_text(f.get('provider'))} / **Resource:** `{safe_text(f.get('resource_id'))}`")
        lines.append(f"- **Description:** {safe_text(f.get('description'))}")
        lines.append(f"- **OWASP:** {', '.join(f.get('owasp') or []) or 'N/A'}")
        lines.append(f"- **MITRE ATLAS:** {', '.join(f.get('atlas') or []) or 'N/A'}")
        lines.append(f"- **NIST AI RMF:** {', '.join(f.get('nist_ai_rmf') or []) or 'N/A'}")
        lines.append(f"- **NIST CSF:** {', '.join(f.get('nist_csf') or []) or 'N/A'}")
        lines.append(f"- **Remediation:** {safe_text(f.get('remediation'))}")
        lines.append("")
    return "\n".join(lines)


def render(findings: list[dict[str, Any]], template_path: Path | None = None) -> str:
    values = {
        "total_findings": str(len(findings)),
        "severity_table": severity_table(findings),
        "provider_table": provider_table(findings),
        "detailed_findings": detailed_findings(findings),
    }
    if template_path and template_path.exists():
        template = template_path.read_text(encoding="utf-8")
        for key, value in values.items():
            template = template.replace("{{ " + key + " }}", value).replace("{{" + key + "}}", value)
        return template
    return "\n".join([
        "# Cloud-Hosted AI Model Security Scan Report",
        "",
        "## Executive Summary",
        f"Total findings: **{len(findings)}**",
        "",
        "## Severity Breakdown",
        severity_table(findings),
        "",
        "## Findings by Provider",
        provider_table(findings),
        "",
        "## Detailed Findings",
        detailed_findings(findings),
        "## Redaction Notice",
        "Potential credentials, bearer tokens, API keys, passwords, and secret-like fields are redacted before report rendering.",
    ])


def main() -> int:
    parser = argparse.ArgumentParser(description="Render redacted Markdown report from scanner findings")
    parser.add_argument("--findings", required=True, type=Path)
    parser.add_argument("--out", required=True, type=Path)
    parser.add_argument("--template", type=Path)
    args = parser.parse_args()
    findings = load_findings(args.findings)
    args.out.parent.mkdir(parents=True, exist_ok=True)
    args.out.write_text(render(findings, args.template), encoding="utf-8")
    print(f"redacted report written to {args.out}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

Validation checklist and operating rules

Use this checklist before running against production or regulated workloads.

Human-in-the-loop escalation

  • Stop and escalate when a production guardrail bypass is confirmed or suspected.
  • Stop and escalate if any test returns secrets, credentials, regulated personal data, PHI, payment-card data, or customer-confidential data.
  • Stop and escalate if an endpoint attempts tool/plugin/MCP/API actions with side effects.
  • Escalate medium/high findings where telemetry is missing.

Operational hardening

  • Run from a dedicated security account/subscription with centralized logging and egress controls.
  • Use AWS STS and Azure workload identity instead of long-lived secrets.
  • Store evidence in immutable or versioned encrypted storage.
  • Separate inventory-only mode from invocation mode.
  • Use canary endpoints before production scans.

Pre-execution checklist

1SKILL.md passes metadata validation and uses a supported subdomain for the local validator version.
2scan_scope.yaml validates and has not expired.
3AWS role assumption and Azure identity checks pass.
4The scanner can inventory cloud resources before invocation mode is enabled.
5Every endpoint invocation is approved, rate limited, and logged.
6Findings include evidence, resource IDs, timestamps, framework mappings, confidence, severity, and remediation.
7Reports are reviewed by a human before distribution or ticket creation.
